AI QA STUDIO

From requirements to evidence.

Windows x64 desktop package. Extract, configure AI once, and start.

Node, Python and the test browser included

First start

1
Extract the entire ZIP

Use a writable local folder such as C:\AIQA. Run launchers from the extracted folder.

2
Double-click Configure AI.cmd

Enter your own Gemini key in the local settings page and save. Get your Gemini key.

AI generation requires internet and provider quota. Your key is saved locally; it is not included with the package.
3
Double-click Start AI QA Studio.cmd

Wait for Ready. The application opens automatically. Keep the launcher window open.

Application: http://127.0.0.1:3000/

4
Use Stop AI QA Studio.cmd when finished

Saved projects are preserved. Next time, simply double-click Start again.

Try the client demo

Double-click Start Client Demo.cmd, then Load Demo Project.cmd.

This prepares six requirements and eight linked draft tests. Review, connect, approve and run them. The intentional cart defect gives seven passes and one failure. Fix the demo mode and re-test to show the defect lifecycle.

The supplied demo runs without an AI key. To demonstrate AI-generated drafts, configure your key and use a separate project.
