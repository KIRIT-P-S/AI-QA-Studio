Set up once. Start with a double-click.

For Apple Silicon Macs with macOS 14 Sonoma or later.

macOS blocked a launcher?

These command files are unsigned and not notarized. For the trusted original package, click Done, then open System Settings > Privacy & Security. Choose Open Anyway for the named launcher and confirm Open.

Approve each launcher if requested. Run Setup Mac.command before configuration and start. Managed Macs may require administrator approval.

Apple's instructions

First use

  1. Extract the full ZIP into a writable local folder such as Documents/AIQA.
  2. Double-click Setup Mac.command. Keep Terminal open until Setup complete. It downloads and installs the app's own Node, Python, dependencies and testing browser, then builds the application.
  3. Double-click Configure AI.command and enter your own Gemini key. Create a key. Supplied tests can run without AI configuration.
  4. Double-click Start AI QA Studio.command. The studio opens in your browser. Keep the launcher Terminal window open.
  5. Use Stop AI QA Studio.command when finished.

First-time setup needs internet access. It does not install Homebrew, require sudo or change your system Python.

Client demo

Run Start Client Demo.command, then Load Demo Project.command.

Six requirements and eight linked draft tests are prepared for review. Approve and run them to see the intentional cart failure. Fix the demo mode and re-test to show the issue lifecycle.
